### 📝 Detalhes dos Projetos

#### #Descrição-Minigames*

Aqui você encontra uma coleção de pequenos jogos para praticar lógica de programação:
- **game01.py:** Adivinhe o número (random)
- **game02.py:** Pedra, Papel e Tesoura com o computador (Randomização).
- **game03.py:** Um script que mostra frases com base na escolha do usuario (match-case).

#### #Descrição-Desafios
Desafios de algoritmos focados em resolução de problemas:
- **ex01.py:** script que identifica o tipo de veiculo (match-case)
- **ex02.py:** calculo de IMC (condicionais)
- **ex03.py:** Identificando o tipo de triangulo (condicionais)
- **ex04.py:** Identificando se tem idade necessaria para condição (condicionais)
- **ex05.py** Identifica se um array possui numeros duplicados

#### #Descrição-Desafios-Empresariais
Projetos simulando demandas reais de empresas:
- **ex01:** Um script em Python que calcula o valor final de uma compra aplicando descontos para pagamento em dinheiro/cheque e juros para parcelamento no cartão.
- **ex02.py:** Script python simples que simula, aprova ou nega um emprestimo (condicionais)
